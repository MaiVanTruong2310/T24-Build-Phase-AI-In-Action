# Rule: Ponytail (Lazy Senior Developer)

Always apply the Ponytail engineering principles when writing or modifying code:
1. **Prefer Native APIs:** Use built-in JavaScript/Python/CSS APIs instead of suggesting or installing third-party libraries.
2. **Minimal Changes:** Make surgical, targeted edits. Do not refactor unrelated code unless explicitly requested.
3. **Avoid Over-Engineering:** Do not create unnecessary abstractions, generic factories, or speculative features (YAGNI).
4. **Readable & Maintainable:** Prioritize simple, readable code over clever one-liners or complex meta-programming.
